# 香港官方中文游戏名设计规格

**日期：** 2026-07-26  
**状态：** 已实施，质量门禁通过，待管理员确认提交推送
**范围：** 将既有与未来订阅的游戏展示名统一为可核验的大陆官方中文优先、香港官方中文次之、人工中文再次、官方英文回退；不改变商品身份、地区监控范围、价格采集或价格 ID。

**实施记录：** 已通过迁移 `0007_game_name_sources.sql` 持久化 `name_zh_source`；新增 `POST /api/products/preview-game-names`、`POST /api/subscriptions/sync-game-names` 和 `POST /api/subscriptions/sync-game-names/confirm` 三个管理员接口。展示层取消旧标题词表，只原样使用非空已保存名称，否则原样回退英文。

## 1. 目标与固定规则

所有订阅在仪表盘、订阅详情、Telegram 日报和异常通知中使用同一份已保存的展示名。名称的优先级固定如下：

1. 与唯一香港官方 `titles/{数字 ID}` 精确对应的腾讯 Nintendo Switch 官方 `software/{同一数字 ID}` 页面标题。
2. 未找到大陆官方页面时，通过任天堂香港商店官方商品身份核验的繁体中文标题，转换为简体中文后保存和展示。
3. 未找到可验证的大陆或香港官方商品时，由管理员填写的中文名称。
4. 管理员未填写中文名称时，默认区或现有记录中的原官方英文标题。

系统不使用机器翻译、AI 翻译、第三方翻译站或未经核验的浏览器文本。香港官方标题的繁转简只服务于简体中文界面可读性，不能参与跨区匹配、`normalized_name`、官方 URL、价格 ID、采集或价格校验。

## 2. 数据模型与来源保护

`games.name_zh` 继续承载统一展示名。新增 `name_zh_source` 记录来源，枚举值为：

| 来源 | 写入条件 | 自动同步是否可覆盖 |
| --- | --- | --- |
| `mainland_official` | 腾讯 Nintendo Switch 官方 `software/{ID}` 与香港官方 `titles/{同一 ID}` 精确对应 | 可以 |
| `hong_kong_official` | 无大陆官方同 ID 页面时，已验证香港官方繁中标题成功转换为简体 | 可以 |
| `manual_chinese` | 香港标题不可验证且管理员填写非空中文名 | 不可以 |
| `official_english_fallback` | 香港标题不可验证且管理员未填写中文名 | 可以 |
| `legacy_pending_sync` | 上线前已有记录，尚未按新规则处理 | 可以 |

迁移为既有记录设置 `legacy_pending_sync`，不修改其现有显示文字。这样上线和迁移本身不触发任天堂网络请求，也不会因为一次外部临时失败错误改名。展示名称同步由受认证管理员显式发起。

## 3. 香港官方标题的核验与转换

Worker 从既有订阅的地区商品读取官方锚点，不接受浏览器提交的标题、地区或 URL。它复用现有香港官方搜索与详情解析器，以锚点的商品类型、发行商、受控本地化身份和官方 URL 白名单核验候选；只有唯一、已证明属于同一逻辑商品的香港官方 `titles/{数字 ID}` 候选可继续进入名称来源解析。

Worker 先把该香港 URL 中的数字 ID 用于构造固定的腾讯 Nintendo Switch 官方 `https://www.nintendoswitch.com.cn/software/{ID}` 请求。页面主机、路径与请求 ID 必须精确匹配；解析到非空大陆标题才保存为 `mainland_official`。腾讯页面不存在、重定向、标题缺失或香港商品不是 `titles/{数字 ID}` 时，不得尝试按文字、发行商或搜索结果猜测大陆译名，直接进入香港繁转简回退。

若订阅已经包含已确认的香港地区商品，优先重读该商品详情取得标题；否则才使用受控香港官方检索与身份规则查找。搜索不可用、结果歧义、类型或发行商不符、官方 URL 无法验证均视为“找不到”，不写入猜测名称。

标题转换使用离线、确定性的繁简转换词典。转换过程不发送标题给任何外部服务；转换异常与外部读取失败均返回“不可用”，交由管理员填写中文或确认官方英文，禁止静默使用机器翻译或保存猜测名称。

## 4. 既有订阅同步体验

仪表盘新增“同步游戏名称”操作。管理员选择需要处理的现有订阅后，浏览器调用受认证同步接口：

- 大陆官方同 ID 页面核验成功的订阅直接更新为大陆名称并标记 `mainland_official`；无大陆页面但香港标题核验成功时，才更新为繁转简名称并标记 `hong_kong_official`。
- 其余订阅显示原官方英文标题和可选中文输入框；管理员可填写中文并确认保存，或确认保留英文并标记 `official_english_fallback`。
- 普通同步对 `manual_chinese` 项只返回待决策，不访问外部来源也不直接覆盖；管理员主动提交该项的最终决定时，Worker 会再次核验官方名称，若官方名称已恢复则按固定优先级写入官方名称，否则才保存新的人工中文或英文回退。
- 批处理以单项结果返回：一个商品的香港查询失败不会阻断其他商品；每个实际名称写入都验证订阅与游戏归属，禁止浏览器借 ID 改写不在选择范围内的游戏。

同步操作不加载仪表盘时自动执行，避免普通页面访问产生外部请求、缓慢加载或因任天堂暂时故障改变当前展示。

## 5. 新增订阅体验

在订阅向导最终确认前，Worker 用已确认默认区商品为锚点执行同一香港官方标题解析：

- 成功时优先预览并保存大陆官方名称与 `mainland_official` 来源；无大陆同 ID 页面时，预览并保存转换后的香港简体名称与 `hong_kong_official` 来源。
- 无法确认时，向导显示可选“中文展示名称”输入框，并同时说明留空将使用官方英文标题。
- 后端不信任浏览器提交的“官方”来源：只有服务端成功核验时才能写入 `hong_kong_official`；浏览器输入只能写入 `manual_chinese` 或明确的英文回退。

这不要求把香港区加入监控范围，也不创建额外的地区商品、价格快照或官方价格 ID。

## 6. 接口、权限与错误边界

新增三个受认证接口：`POST /api/products/preview-game-names` 只预览名称来源、`POST /api/subscriptions/sync-game-names` 只同步管理员选中的既有订阅、`POST /api/subscriptions/sync-game-names/confirm` 保存逐项人工中文或英文回退决定。订阅确认输入也携带可选人工中文名称。所有写操作均由现有管理员会话守卫保护。错误响应只返回可操作的简体中文摘要，例如“未找到可验证的香港官方标题”，不回显任天堂 HTML、外部响应、Cookie、内部匹配评分或数据库错误。

同步和新建均应把外部网络、解析或繁简转换失败降级为“可填写中文或保留英文”，不能阻断合法的商品订阅，也不能用错误的自动名称替代。

## 7. 测试与验收

- 纯函数测试覆盖官方繁中标题的确定性繁转简、转换异常安全降级和不改变商品身份字段。
- 提供方与服务测试覆盖：大陆 `software/{ID}` 只接受与已核验香港 `titles/{同一 ID}` 对应的官方页面、页面不存在时回退香港、唯一香港候选才接受、歧义/类型或发行商不符拒绝、人工中文优先保存、空输入英文回退，以及人工名称不被同步覆盖。
- API 测试覆盖匿名拒绝、批量项目独立结果、订阅/游戏归属校验和错误脱敏。
- 页面测试覆盖同步结果中的官方成功、人工输入、英文确认，以及仪表盘、详情、日报和通知一致使用保存的展示名。
- 完整 Worker、前端、类型检查、生产构建和 `git diff --check` 通过；同时人工核对新增或修改的中文注释仍与实现一致。

## 8. 明确不做的事

- 不把香港地区自动加入订阅，不变更已选地区、商品 URL、官方价格 ID、快照、汇率或目标价。
- 不回填无法被官方身份规则证明的中文名，不猜测同名、DLC、本体、组合包或升级包之间的对应关系。
- 不接入在线翻译、AI、任天堂登录态或第三方标题数据库。
- 不在本次设计中部署生产、修改版本号或创建 Git 提交；提交与推送须在实施完成后另获管理员明确确认。
