# 目标价功能彻底移除设计

日期：2026-08-10  
状态：待用户审查

## 1. 背景与目标

项目当前提供全局人民币目标价、单区当地货币目标价、命中状态机及 Telegram 目标价通知。用户确认不再需要该能力，并明确授权永久删除已有目标价配置与对应通知历史。

本次目标是在不影响普通官方降价提醒、采集失败/恢复通知、订阅启停、地区编辑、价格历史和日报的前提下，从当前运行路径彻底移除目标价 UI、API、领域模型、服务、仓储、数据库结构、测试和活跃文档。

## 2. 明确范围

### 删除

- 详情页中的全局/单区目标价输入、保存按钮、草稿状态和相关客户端类型。
- `PATCH /api/subscriptions/:id` 的目标价请求分支及响应字段；旧载荷将按普通无效订阅更新返回 `422`，不保留兼容入口。
- `SubscriptionService.setTargets`、订阅写仓储的目标价写入、详情查询的目标价读取及全部端口字段。
- 目标价命中/重置状态机、`target-price` 通知事件类型、消息模板以及创建该事件的采集规则。
- PostgreSQL 中 `subscriptions.global_target_cny_fen`、`subscription_region_targets` 表、该表的所有历史数据，以及 `notification_events` 中全部 `target-price` 行。
- 目标价专用测试、夹具和活动文档描述。

### 保留

- 官方价格下跌提醒、采集失败/恢复通知及其去重/投递机制。
- 订阅的启停、地区商品范围、详情、永久删除和价格历史。
- 既有 `0001_initial.sql` 与历史验收记录中对目标价的历史文字。迁移账本校验依赖该文件精确字节，历史证据也不能伪造为从未存在过该功能。

## 3. 数据库迁移与数据处理

新增按文件名字典序执行的 PostgreSQL `0002_remove_target_price.sql` 迁移，其事务顺序为：

1. 删除 `notification_events` 中 `event_type = 'target-price'` 的历史行。
2. 删除 `subscription_region_targets` 表及全部目标金额/命中状态。
3. 删除 `subscriptions.global_target_cny_fen` 列。

迁移不修改历史迁移文件，也不触碰其他通知事件、订阅、地区映射、价格快照、汇率、设置或认证数据。空库与已包含目标价数据的库均必须可迁移；重复启动由迁移账本保证不会重复执行。

备份恢复的精确表集合由 16 张更新为 15 张，恢复前校验不再允许 `subscription_region_targets` 存在。

## 4. 应用行为

订阅详情 API 不再返回 `globalTargetCnyFen` 或 `regionTargets`。订阅更新仅支持现有的启用状态和地区范围两种合法载荷。商品采集只计算官方降价、失败和恢复通知，不再计算阈值命中或重置。

前端详情页不保留目标价草稿或表单。因而页面重新加载、订阅切换、权限失效和删除确认均不再携带无用的目标价内存状态。

## 5. 测试与验收

- 先写迁移回归：用包含全局/单区目标价和各类通知的真实 PostgreSQL 夹具验证迁移后仅目标价数据消失，其他业务数据保留。
- 更新 API、仓储、服务和 DOM 测试，断言响应与详情页均无目标价字段/UI，目标价 PATCH 被 `422` 拒绝。
- 更新通知、迁移与备份恢复测试，断言 `target-price` 不再是合法事件类型，数据库精确表集合为 15 张。
- 执行完整 Vitest、DOM、TypeScript、生产构建、Docker/备份合同及空白检查；确认新增/修改注释和实现一致。

## 6. 风险与边界

迁移不可逆：已有目标价配置和历史目标价通知不会保留，也不提供恢复接口。运行生产/NAS 迁移前仍应按既有部署流程制作经过验证的 PostgreSQL 备份；本次仅获得代码与迁移实现授权，不代表获得 NAS 写入或生产迁移执行授权。

普通降价提醒与目标价提醒共享部分通知基础设施，实施必须通过事件类型和价格规则测试确认只删除目标价分支，不能误删官方降价、采集失败或恢复事件。
