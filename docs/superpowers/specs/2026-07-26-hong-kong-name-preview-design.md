# 港区核验即时中文名预览设计

**状态：** 已实施，待管理员确认提交推送

## 目标

管理员点击“核验其他地区”后，向导立即为每个已选游戏取得名称预览。港区存在已验证候选时，港区卡片以最终中文名为主标题、该港区官方英文标题为副标题；不以浏览器词表或机器翻译推断中文名。

## 数据流与展示规则

1. 向导继续先调用既有地区核验接口，获得受 Worker 认证的各区候选或人工链接状态。
2. 地区核验成功后，向导使用当前已确认地区构造既有名称预览请求；Worker 仍通过同 ID 大陆官方标题、香港官方繁转简、不可用三种受控结果回应。
3. 港区已确认时，卡片主标题使用名称预览的中文名；卡片副标题保留 `canonicalTitle`，方便管理员核对港区官方文字。名称预览不可用时主标题继续使用官方原始标题，并明确提示将在最终确认时选择人工中文或英文回退。
4. 港区需要人工官方链接时，不预先猜测名称；卡片说明“核验后可确定中文名称”。链接核验成功后重新请求预览并按同一规则刷新。
5. 最终确认服务不信任页面预览，继续重读官方来源并按既定优先级写入。预览失败绝不创建订阅、不改变地区映射或覆盖人工决定。

## 仪表盘与生产数据

新订阅仍由确认服务原子写入，并通过仪表盘读取已保存的 `games.name_zh` 展示。生产数据库必须在部署 Worker 前应用 `0007_game_name_sources.sql`；该迁移仅新增来源列并保留历史名称。迁移后的重新添加订阅应写入 `games`、`subscriptions` 与地区关联，仪表盘刷新即可读取。

## 测试与验收

- DOM 测试：核验其他地区后，已确认港区卡显示 Worker 返回的最终中文主标题和英文副标题。
- DOM 测试：港区尚待人工链接时不伪造中文名；链接核验成功后预览刷新。
- DOM 测试：名称预览不可用时保留官方标题并显示人工/英文回退说明。
- 既有确认服务测试继续证明最终写入重新核验名称，不能接受浏览器预览文本。
- 通过相关 DOM 回归、类型检查和构建；更新需求追踪与 API/界面文档中的即时预览规则。
